## Scope

This policy describes the files and browser-extension code in this repository. It does not control the privacy practices of GitHub, Claude, ChatGPT, Manus, a browser, an LLM provider, or any third-party website where the extension may run. Review those providers' policies separately.

## Data processed by the current extension

The extension reads text from a page composer only when it evaluates a submission event. It may temporarily hold the current prompt and the answers entered into the clarification panel in memory so it can append a clarification brief. The current MVP does not include analytics, telemetry, advertising, cookies, tracking pixels, iframes, third-party embeds, or a project-operated server. It does not automatically upload prompts to the project owner.

The extension uses browser local storage for settings such as whether interception is enabled, whether local retention is selected, and the optional analysis-endpoint field. The current MVP does not call that endpoint. The field is reserved for possible future functionality and should be treated as inactive until a future release documents and implements it.

## User choices and deletion

Disable the extension or remove it from the browser to stop processing. Clear the extension's site data through browser settings to remove locally stored settings. Do not use the extension with secrets or confidential content unless you have reviewed the host site's permissions and the extension source.

## Third-party services

GitHub hosts the source repository and release files. The extension may be installed on pages operated by third parties, including LLM providers. Those sites can process page content independently of this project. The project has not embedded third-party analytics or content in the extension.

## Children and sensitive data

This is not designed as a service for children. Do not use it to process highly sensitive personal data, passwords, authentication tokens, health records, financial account information, or confidential business material unless you have the necessary authority and have reviewed every service involved.
