## Scope

This policy describes the files and browser-plugin code in this repository. It does not control the privacy practices of GitHub, Claude, ChatGPT, Manus, a browser, an LLM provider, or any third-party website where the plugin may run. Review those providers' policies separately.

## Data processed by the current plugin

The plugin detects common composers and reads their text locally to determine whether an empty composer is ready for insertion. It may temporarily hold the configured instruction and the current page state in memory. It does not ask questions, archive prompts, intercept submissions, or automatically upload prompt text to the project owner.

The plugin uses browser local storage for settings such as whether automatic insertion is enabled, whether local retention is selected, the customized opening instruction, and the optional analysis-endpoint field. Turning automatic insertion off preserves the saved instruction but prevents new automatic insertions. The current release does not call the optional endpoint.

The current repository does not include analytics, telemetry, advertising, cookies, tracking pixels, iframes, third-party embeds, or a project-operated server.

## User choices and deletion

Use the options page to disable automatic insertion without deleting the saved instruction. Edit or clear the instruction there, or delete the inserted text directly from a composer. Remove the extension or clear its browser extension storage to delete locally stored settings. Do not use the plugin with secrets or confidential content unless you have reviewed the host site's permissions and the plugin source.

## Third-party services

GitHub hosts the source repository and release files. The plugin may be installed on pages operated by third parties, including LLM providers. Those sites can process page content independently of this project. The project has not embedded third-party analytics or content in the plugin.

## Children and sensitive data
