# Cookie Policy

**Last updated:** 2026-09-21

## Current project behavior

The browser extension and repository files do not set, read, or require cookies. They do not include Google Analytics, advertising tags, tracking pixels, social widgets, iframes, or other third-party embeds. The extension uses browser extension local storage for settings; local storage is not a cookie, but it is still described in the Privacy Policy.

The project does not operate a separate hosted website or analytics dashboard. GitHub may use its own cookies and similar technologies when you visit the repository or release pages. Those technologies are controlled by GitHub, not by this project; review GitHub's policies for details.

## Future changes

If analytics, advertising, embedded media, a hosted documentation site, or non-essential cookies are added, this policy must be updated before deployment. A consent mechanism may be required depending on the jurisdiction, technology, purpose, and provider. Analytics should not be described as anonymous or consent-exempt without a jurisdiction-specific review.
